# PostgreSQL Basics – Database Management

## About This Project
This repository contains my beginner-level SQL practice using PostgreSQL. I created databases and tables, inserted records, retrieved data, and performed basic deletion operations.

## Topics Covered

1. Creating a Database
2. Creating a Table
3. Inserting Data into a Table
4. Retrieving Data using SELECT
5. Deleting Rows using DELETE
6. Deleting Columns using ALTER TABLE

## Tools Used
- PostgreSQL
- pgAdmin 4
- SQL

## Project Structure

- `01_create_database.sql` – Creating a database
- `02_create_table.sql` – Creating tables
- `03_insert_data.sql` – Inserting records
- `04_select_data.sql` – Retrieving records
- `05_delete_operations.sql` – Deleting rows and columns

## What I Learned

- How to create and manage databases.
- How to create tables with different columns and data types.
- How to insert records into tables.
- How to retrieve data using SELECT.
- How to delete specific rows.
- How to remove columns from an existing table.
